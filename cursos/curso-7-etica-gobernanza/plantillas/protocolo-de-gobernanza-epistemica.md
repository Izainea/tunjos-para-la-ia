## 3. Roles

Cuatro roles. Una persona puede ocupar varios si lo declara y dice qué se pierde. La separación entre quien produce y quien revisa es la regla que hace a los roles algo más que nombres.

| Rol | Qué hace | Persona (nombre y cargo o relación con el proyecto) | Si una persona ocupa varios roles, qué se pierde |
|---|---|---|---|

| Revisa | Contrasta las lecturas del modelo con el perfil de exclusiones y los registros, sin haberlas producido | | |
| Lector situado | Lee las piezas que la auditoría marcó, antes que el modelo | | |
