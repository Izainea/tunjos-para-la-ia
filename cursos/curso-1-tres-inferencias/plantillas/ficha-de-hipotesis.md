## El filtro

Peirce da cuatro criterios para elegir qué hipótesis perseguir. Aplíquelos a cada una con razones, no con sí o no.

| Criterio | H1 | H2 | H3 |
|---|---|---|---|
| **Explica el hecho.** Si fuera verdad, ¿el hecho sorprendente sería natural? | | | |
| **Es verificable.** ¿Qué observación la confirmaría o la refutaría? ¿Está a mi alcance? | | | |
| **Economía.** ¿Cuánto cuesta probarla? ¿Cuánto rinde si acierta? ¿Deja abiertas otras vías o las cierra? | | | |
